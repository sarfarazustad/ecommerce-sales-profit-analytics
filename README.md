# E-Commerce Sales & Profit Analytics

## Project Overview
An end-to-end data analytics project covering sales, revenue, profit, customer and product analysis using Python, SQL and Power BI.

## Tools & Technologies
- Python (Pandas, Matplotlib/Seaborn where applicable)
- SQL
- Power BI
- Excel/CSV

## Project Structure
```text
ecommerce-sales-profit-analytics/
│
├── data/
│   ├── customers.csv
│   ├── orders.csv
│   └── products.csv
│
├── python/
│   └── ecommerce_analysis.py
│
├── sql/
│   └── ecommerce_analysis.sql
│
├── powerbi/
│   └── dashboard_screenshots/
│       ├── page1.png
│       ├── page2.png
│       └── page3.png
│
├── reports/
│   └── project_report.pdf
│
└── README.md
```

## Analysis Areas
- Revenue and sales performance
- Product performance
- Customer analysis
- Profitability analysis
- Discount analysis
- Power BI dashboard reporting

## Files
The `data` folder contains the project datasets. Python analysis is stored in `python/`, SQL queries in `sql/`, dashboard images in `powerbi/dashboard_screenshots/`, and the final report in `reports/`.
